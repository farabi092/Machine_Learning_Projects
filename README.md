
# Machine Learning & Data Science Projects

A collection of hands-on Machine Learning  projects completed.
This repository covers practical applications of supervised learning, regression, classification, and Natural Language Processing (NLP), with an emphasis on data preprocessing, model development, evaluation, and performance analysis.

## Projects

### 1. Iris Classification
**Category:** Multi-Class Classification

Build a classification pipeline to predict Iris flower species using the Iris dataset.

- Dataset: Iris Dataset
- Models: Logistic Regression, Decision Tree
- Techniques: Feature Scaling, Train-Test Split, Model Evaluation
- Evaluation: Accuracy, Precision, Recall, F1-Score, Confusion Matrix

[View Project →](./IRIS%20Classification/)

### 2. Housing Regression
**Category:** Regression

Develop regression models to predict housing prices using housing-related features.

- Dataset: California Housing Dataset
- Focus: Data Preprocessing, Feature Engineering, Regression Modeling
- Evaluation: MAE, RMSE, R² Score

[View Project →](./Housing_Regression/)

### 3. Customer Churn Classifier
**Category:** Classification

Develop a predictive classification model to identify customers who are likely to discontinue a service.

- Focus: Customer Data Analysis and Preprocessing
- Techniques: Feature Encoding, Classification, Model Evaluation
- Evaluation: Classification Metrics and Model Performance Analysis

[View Project →](./Customer_Churn_Classifier/)

### 4. NLP Sentiment Classification
**Category:** Natural Language Processing

Build a text classification pipeline to identify sentiment in customer reviews.

- Dataset: Customer Sentiment Reviews
- Models: Multinomial Naive Bayes, Logistic Regression
- Techniques: Text Preprocessing, TF-IDF Vectorization, Sentiment Classification
- Evaluation: Accuracy, Precision, Recall, F1-Score
- Includes custom text prediction examples.

[View Project →](./NLP%20Sentiment%20Classification/)

## Getting Started

### Prerequisites

- Python 3.x
- pip
- Jupyter Notebook

### Clone the Repository

```bash
git clone https://github.com/farabi092/Machine_Learning_Projects.git
cd Machine_Learning_Projects
```

### Set Up a Virtual Environment

```bash
python -m venv venv
```

**Windows:**
```bash
venv\Scripts\activate
```

**macOS / Linux:**
```bash
source venv/bin/activate
```

### Install Dependencies

Install the required libraries for the project you want to run:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Additional dependencies may be required for individual projects.

### Run Jupyter Notebook

```bash
jupyter notebook
```

Navigate to the desired project folder and open its notebook.
